# `data/` — local data zone (git-ignored)

Nothing in this folder except this README and `.gitkeep` files is committed. Every
layer is regenerated by the pipeline from the single source file.

| Folder | Layer / purpose | Written by | Format |
|---|---|---|---|
| `source/` | **Original file** (`world_air_quality.csv`) — place it here yourself; verified against `contracts/source_manifest.yml` | you | CSV (as published) |
| `raw/committed/` | Raw landing copy: every source field as an exact string + lineage columns, one file per ingest batch | `ingest_source` → `validate_raw` | Parquet |
| `raw/_pending/` | A batch that has been ingested but not yet validated | `ingest_source` | Parquet |
| `quarantine/` | Batches that failed `validate_raw` (kept for inspection, never read downstream) | `validate_raw` | Parquet |
| `checkpoints/` | `ingest_checkpoint.json` — source-row high-water mark + committed batch list | `validate_raw` | JSON |
| `staging/` | `air_quality_readings` — typed, cleaned, de-duplicated readings | `transform_staging` | Parquet |
| `curated/` | `station_day_pollutants` (data product) + `partitions/` demo | `build_curated` | Parquet |
| `features/` | `model_features` — model-ready dataset | `build_curated` | Parquet |
| `outputs/runs/<run_id>/` | Everything one run produced: models, split, metrics, predictions, DQ report, run summary | `train_model` … `publish_outputs` | JSON / CSV / joblib |
| `outputs/latest/` | Promoted copy of the last **successful** run | `publish_outputs` | JSON / CSV |
| `benchmark/` | Storage benchmark files (CSV / JSON / Parquet) | `pipeline benchmark` | various |
| `tmp/` | Scratch space, e.g. failure-injection copies | scripts | — |
